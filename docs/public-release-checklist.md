# Public Release Checklist

- [ ] No `.env` files, credentials, private keys, certificates, or tokens
- [ ] No customer/client identities, records, screenshots, reports, or exports
- [ ] No internal URLs, IP addresses, hostnames, database names, or production configuration
- [ ] No private prompts, source corpora, vector stores, embeddings, or model traces
- [ ] No generated builds, dependencies, caches, logs, local databases, or coverage reports
- [ ] Catalogue and media are synthetic or cleared for public distribution
- [ ] `npm test`, `npm run typecheck`, `npm run lint`, `npm run build`, and `npm run build:offline` pass
- [ ] Git tracks only intended release files
- [ ] Remote repository visibility is public and the default branch is `main`
- [ ] README, license, contributing guidance, and security policy are current
